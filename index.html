GolfLink

A portable golf statistics, identity, and playing-history ledger. This page is a real, working version of the core idea, scoped to what a static page can honestly do: your rounds are logged and kept in your own browser, and the whole ledger can be exported as a portable JSON file at any time — and that same file can be imported back in on another device or browser to bring your ledger with you.

What's real here, what isn't yet

The round ledger above is genuinely persisted (browser localStorage) and genuinely exportable as a portable JSON file, and the stats above (average score, best round, average putts, round-level fairways-hit % and greens-in-regulation %, and a last-5-vs-lifetime score trend) are computed live from that same real data — that part of "portable statistics and history ledger" is real today. Fairways/GIR are logged as a single count per round (optional, out of 14/18), not per-hole — true hole-by-hole stats (which hole, strokes-gained) still aren't built, since that needs per-hole data this page doesn't collect yet. The exported JSON file can also be imported back in (on this browser or any other), merging in any rounds not already present — that's real, manual, file-based portability across devices. What's still not built: automatic cross-device sync (import is a manual step, not a background sync) and a shareable public identity/profile. This page will be extended as those pieces become real.
