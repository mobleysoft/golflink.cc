GolfLink

A portable golf statistics, identity, and playing-history ledger. This page is a real, working version of the core idea, scoped to what a static page can honestly do: your rounds are logged and kept in your own browser, and the whole ledger can be exported as a portable JSON file at any time.

What's real here, what isn't yet

The round ledger above is genuinely persisted (browser localStorage) and genuinely exportable as a portable JSON file — that part of "portable statistics and history ledger" is real today. What's not built yet: cross-device sync, a shareable public identity/profile, and course-level stat aggregation (fairways, GIR, strokes-gained). This page will be extended as those pieces become real.
